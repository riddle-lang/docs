# 开始使用 Riddle

这一部分只做一件事：让一个最小 Riddle 项目在本机通过检查并运行。语法细节会在后续章节逐步解释。

Riddle `v0.2.0` 提供预编译发布包，也可以从源码安装。两种方式都会得到三个命令：

- `clue`：创建、检查、构建和运行项目；
- `riddlec`：检查单个源码入口并生成 C；
- `riddle-lsp`：向编辑器提供语言服务。

先按[安装 Riddle 工具链](./install.md)完成安装并确认三个命令可用，然后跟随[你好，Riddle](./hello-riddle.md)创建第一个项目，最后在[创建与构建项目](./clue-create.md)中了解清单、入口文件、本地依赖和输出路径。

完成后你应该能够：

- 识别 `Clue.toml`、`src/main.rid` 和 `.clue/build` 的职责；
- 使用 `clue check` 在不生成可执行文件时检查项目；
- 使用 `clue run` 构建并运行程序；
- 看懂函数、变量、结构体和格式化输出在一个完整程序中的位置。
