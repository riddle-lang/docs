# 变量与可变性

变量是给值起名字的方式。在 Riddle 中，变量默认不可变。
这个默认选择让代码更容易推理：当你看到一个普通绑定时，就可以假设它不会在后续被改写。

## 使用 let 创建绑定

最简单的变量绑定使用 `let`：

```riddle
fun main() {
    let answer = 42;
    print(answer)
}
```

这里的 `answer` 绑定到整数 `42`。默认情况下，你不能重新给 `answer` 赋值。

## 默认不可变

下面的代码表达了 Riddle 不希望你在普通绑定上做的事情：

```riddle
fun main() {
    let answer = 42;
    answer = 43; // error: answer 不可变
}
```

不可变默认值有两个好处。
第一，它减少了意外修改。第二，它让移动和引用规则更容易理解，因为一个值不会在你没有注意到的地方被改掉。

## 使用 mut 表示可变

如果一个变量确实需要变化，需要显式写出 `mut`：

```riddle
fun main() {
    let mut count = 0;
    count = count + 1;
    print(count)
}
```

`mut` 是一种提醒：这个绑定后面会发生变化。读代码的人看到 `mut`，就知道需要关注这个值的更新路径。

## 类型标注

变量可以写类型标注：

```riddle
fun main() {
    let age: i32 = 18;
    let name: str = "Riddle";
}
```

很多时候类型可以从初始化表达式推导出来。需要让意图更清楚，或者编译器无法推导时，可以写出类型。

## 只声明不初始化

Riddle 允许先声明一个变量，再在后面赋值：

```riddle
fun main() {
    let value: i32;
    value = 10;
    print(value)
}
```

这种写法适合分支初始化等场景。不过在变量被读取之前，它必须已经被初始化。

## 小结

- `let` 创建变量绑定；
- 变量默认不可变；
- 需要修改时使用 `mut`；
- 类型标注可以显式写出；
- 未初始化变量必须在读取前完成初始化。
