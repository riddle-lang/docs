# 数据与抽象

程序不仅要计算，还要组织数据和行为。Riddle 使用模块组织名字，用结构体和枚举描述数据，用 trait 描述能力，用 impl 把能力实现到具体类型上。

这一部分会介绍：

- 如何用 `mod` 和 `use` 组织名字；
- 如何用 `struct` 和 `enum` 定义数据；
- 如何用 `trait` 定义一组行为；
- 如何用 `impl` 为类型添加函数和实现 trait；
- 如何使用泛型数据类型、泛型 impl 和方法调用。

如果你熟悉 Rust，可以把这一部分理解成接近 Rust 的数据抽象模型，但当前 Riddle 只实现了其中一部分。
如果你不熟悉 Rust，也可以只把它看成一种把数据和能力组织起来的方式。
