# 表达式与块

Riddle 中很多东西都是表达式。表达式会产生值，而语句主要用于执行动作。
理解表达式和块，是理解 Riddle 函数、控制流和所有权规则的基础。

## 表达式会产生值

下面这些都是表达式：

```riddle
1
x + y
foo(1, 2)
point.x
```

表达式可以出现在变量初始化、函数参数、返回值和更大的表达式中。

## 分号会丢弃值

在 Riddle 中，分号表示“把这个表达式当成语句执行，并丢弃它的结果”。

```riddle
fun main() {
    let x = 1 + 2;
    x + 1;
}
```

`x + 1;` 有分号，所以它的结果不会作为函数体返回值。

如果去掉分号，它就会成为块的尾表达式：

```riddle
fun value() -> i32 {
    let x = 1 + 2;
    x + 1
}
```

这个函数返回 `x + 1` 的结果。

## 块也是表达式

块由 `{}` 包围，可以包含多条语句，也可以有一个尾表达式：

```riddle
fun main() {
    let value = {
        let a = 1;
        let b = 2;
        a + b
    };

    print(value)
}
```

这里内部块的值是 `a + b`，因此 `value` 会绑定到这个结果。

## 块创建作用域

块不仅能产生值，也会创建新的作用域：

```riddle
fun main() {
    let outer = 1;

    {
        let inner = 2;
        print(inner);
    }

    print(outer)
    // inner 在这里不可用
}
```

作用域会影响变量何时失效，也会影响引用是否逃逸。后面的“引用与逃逸”会详细解释这一点。

## 小结

- 表达式会产生值；
- 分号会把表达式变成语句并丢弃结果；
- 块可以包含语句和尾表达式；
- 块会创建新的作用域；
- 作用域会影响变量生命周期和逃逸分析。
