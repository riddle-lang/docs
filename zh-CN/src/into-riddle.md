# 进入 Riddle 编程世界

Riddle 是一门受 Rust 和 Go 启发的实验性工程语言。它尝试把静态类型、移动与借用检查、确定性析构、自动逃逸分配和 C 互操作放进一套相对直接的语法与工具链中。

## Riddle 解决什么问题

Riddle 关注的不是覆盖所有应用领域，而是验证一组能否共同工作的设计选择：

- 值默认移动，只有实现 `Copy` 的类型按复制语义传递；
- 共享引用和可变引用在编译期接受借用检查；
- 非逃逸值优先保留在栈上，可能越过当前栈帧的值由逃逸分析提升到保守式非移动 GC 堆；
- `Drop` 仍按所有权边界确定性执行，存储位置不会改变移动、借用或析构语义；
- 高层代码使用结构体、枚举、trait、impl、泛型和模式匹配组织；
- 当前后端生成 C11，Clue 负责项目检查、构建和运行，`riddle-lsp` 提供编辑器能力。

这些选择借用了成熟语言的经验，但组合方式属于 Riddle。尤其不要把“使用 GC 堆”理解成 Kotlin/JVM 式的完全托管对象模型，也不要把“语法接近 Rust”理解成已经支持完整 Rust 语义。

## 当前边界

Riddle 目前只有 C 后端，依赖只支持本地 path，泛型与 callable 以静态单态化为主，也没有类继承或异常。

本书会在第一次出现限制时直接说明。需要一次查看全部实现状态时，请阅读[当前工具链状态](./compiler-status.md)。
