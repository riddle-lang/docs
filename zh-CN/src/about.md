# 关于本书

你可能听说过 Rust, C++, Java 这些风靡一时的语言。这些语言当然不错，
但是这些语言通常都有些小小的缺陷让我们在编写代码的时候可能不是那么愉快。
那么这个时候就轮到 Riddle 来救场了：Riddle 吸收了大部分编程语言的优势并且去除了他们可能糟糕的一部分。

当然的，一个好的语言肯定要配上一个好的教程，这就是为什么出现了本书。
现在 Riddle 还处于开发阶段，可能有大部分特性来不及更新到本书，请谅解。

这本书在编写之初受到了 [Rust Book](https://doc.rust-lang.org/stable/book/) 
和 [Rust 圣经](https://course.rs/into-rust.html) 较大的启发，在此感谢。
