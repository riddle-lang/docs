# Riddle 基础

这一部分建立后续章节共用的语法基础。每章只引入一组紧邻的概念：

1. 用注释说明代码意图，用 `let` 创建绑定，用 `mut` 标记需要改写的绑定；
2. 认识标量、元组、数组、引用和字符串类型；
3. 用函数组织计算，用表达式和块产生值；
4. 用 `if`、`while`、`for` 和 `match` 选择执行路径；
5. 用 `Option`、`Result` 和 `?` 表达可恢复失败，用 `panic` 终止不可恢复的路径。

`match` 的完整模式系统（引用模式、穷尽性检查、匹配人体工学）依赖结构体和枚举知识，放在[枚举、模式与 match](./enums-and-patterns.md)一章；闭包与迭代协议放在[闭包与迭代器](./functional.md)一章。本部分只在必要处提示“值会移动”或“引用会借用”，完整规则集中在[所有权与内存](./ownership-and-memory.md)。
